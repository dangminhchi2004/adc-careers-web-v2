BÁO CÁO CẤU TRÚC VÀ MỤC ĐÍCH CÁC FILE/FOLDER TRONG DỰ ÁN ADC CAREERS

1. TỔNG QUAN DỰ ÁN
Dự án ADC Careers là một website tuyển dụng Full-Stack cơ bản cho Asia Dragon Capital (ADC).
- Ứng viên (Candidates): Có thể xem các vị trí công việc, lọc theo phòng ban, xem chi tiết công việc, điền form ứng tuyển (Modal), và nhận/tải xuống file PDF biên nhận.
- Quản trị viên (Admin): Có thể đăng nhập vào bảng điều khiển (dashboard) để thực hiện các thao tác CRUD (Tạo, Đọc, Cập nhật, Xóa) các vị trí tuyển dụng và quản lý hồ sơ ứng viên.
- Công nghệ sử dụng: Frontend (HTML, CSS, JS thuần), Backend (Node.js + Express.js), Database (MySQL).

---

2. CẤU TRÚC THƯ MỤC CHÍNH

2.1. Thư mục `backend/` (Node.js & Express.js Backend)
Chứa toàn bộ mã nguồn xử lý logic phía máy chủ (API, Database, File Uploads).
- `config/`: Chứa các file cấu hình như kết nối database (db.js), các policy/rules bảo mật.
- `controllers/`: Chứa logic xử lý của các API endpoints (ví dụ: jobController.js, applyController.js, authController.js).
- `middlewares/`: Chứa các middleware của Express (ví dụ: authMiddleware.js để bảo vệ các route dành riêng cho Admin).
- `models/`: Chứa các hàm tương tác với cơ sở dữ liệu MySQL (ví dụ: các câu lệnh SQL để truy vấn Jobs, Applications, Users).
- `routes/`: Định nghĩa các endpoints API và liên kết chúng với Controllers tương ứng.
- `scripts/`: Chứa các script tiện ích (ví dụ: resetAdmin.js dùng để đặt lại tài khoản quản trị).
- `services/`: Chứa các logic nghiệp vụ phức tạp hoặc kết nối bên thứ 3 (ví dụ: sinh file PDF biên nhận).
- `utils/`: Chứa các hàm tiện ích dùng chung trong toàn bộ backend.
- `uploads/`: Thư mục lưu trữ các file tải lên (ví dụ: CV của ứng viên).
- `logs/`: Chứa các file ghi nhận log hoạt động của server.
- `server.js`: File khởi chạy chính của ứng dụng backend (Entry point).
- `seed.js`: Script dùng để tạo ra dữ liệu mẫu (seeding) vào cơ sở dữ liệu MySQL.

2.2. Thư mục `frontend/` (Giao diện người dùng)
Chứa mã nguồn giao diện tương tác (Client-side).
- `index.html`: Trang chủ dành cho ứng viên (hiển thị danh sách công việc, lọc, popup ứng tuyển).
- `admin.html`: Trang quản trị dành cho Admin (yêu cầu đăng nhập) để quản lý vị trí tuyển dụng và hồ sơ ứng viên.
- `login.html`, `auth-zone.html`: Các trang phục vụ cho việc xác thực, đăng nhập của Admin.
- `job.html`: Trang chi tiết cho một vị trí công việc (nếu có tách rời).
- `privacy-policy.html`, `thank-you.html`: Các trang phụ tĩnh như Chính sách bảo mật và Cảm ơn sau khi ứng tuyển.
- `css/`: Thư mục chứa các file CSS định dạng giao diện.
- `js/`: Thư mục chứa các script Javascript phía client (ví dụ: main.js gọi API hiển thị công việc, admin.js quản lý các thao tác admin).
- `assets/`: Thư mục chứa hình ảnh, icon, font chữ,...

2.3. Thư mục `php-backend/` (Phiên bản Backend bằng PHP)
Có thể là phiên bản legacy (cũ) hoặc một giải pháp dự phòng được viết bằng PHP thuần.
- `api/`: Chứa mã nguồn của API.
  - `config/`: Cấu hình database, biến môi trường (db.php, env.php).
  - `controllers/`: Logic xử lý (api.php).
  - `lib/`: Các thư viện tiện ích tự viết (http.php, jwt.php, storage.php).
  - `cvs/`: Nơi lưu trữ CV ứng viên.

3. CÁC FILE QUAN TRỌNG Ở THƯ MỤC GỐC (ROOT)

- `PRD_AND_INSTRUCTIONS.md`: Tài liệu đặc tả yêu cầu sản phẩm (Product Requirements Document). Chứa mọi thông tin chi tiết về tính năng, cấu trúc Database schema, luồng hoạt động của API và giao diện.
- `README.md`: Tài liệu hướng dẫn thiết lập và khởi chạy dự án dành cho developer (Clone, cài đặt dependencies, cấu hình database, run/build project).
- `package.json` & `package-lock.json`: Quản lý các dependencies (thư viện như express, mysql2, cors, multer...) và các script chạy node (start, dev, seed) của dự án.
- `.env` & `.env.example`: File chứa các biến môi trường cấu hình như PORT, thông tin đăng nhập Database, JWT_SECRET, Admin credentials. (.env không được push lên git).
- `adc_careers.sql`: File dump cơ sở dữ liệu MySQL dùng để import cấu trúc bảng và dữ liệu mẫu ban đầu (schema).
- `DEPLOY_RENDER.md` & `render.yaml`: File hướng dẫn và cấu hình để deploy ứng dụng lên nền tảng Render.com.
- Các file văn bản, chính sách: `.docx`, `.txt`, `.png` (như Quy Định Bảo Mật, Điều Khoản Sử Dụng, Cookie Policy) dùng làm nội dung pháp lý cho website.
- `ADC_Careers_TestCases.xlsx`: File excel chứa các kịch bản kiểm thử (Test cases) để đảm bảo chất lượng hệ thống.
- `.gitignore`: Chứa danh sách các file/folder bỏ qua không commit lên Git (node_modules, .env, uploads,...).
